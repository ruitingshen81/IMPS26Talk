# IMPS 2026 Talk

Slide deck for **Context-Aware Modeling of Test-Taking Clickstream Data Using a Transformer Model**,  by Ruiting Shen and Klint Kanopka at IMPS 2026.

The presentation is built with [Slidev](https://sli.dev/).

## Run locally

```bash
npm install
npm run dev
```

Then open the local URL printed by Slidev.

## Build

```bash
npm run build
```

The main entry point is [`slides.md`](./slides.md), with section content under [`pages/`](./pages/).
